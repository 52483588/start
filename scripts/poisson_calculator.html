📐 算法说明

模型：X ~ Poisson(λ)，P(X=k) = λk·e−λ/k!

半数盘 (X.5)：大 = X ≥ X+1，小 = X ≤ X

整数盘 (X.0)：大 = X ≥ X+1，小 = X ≤ X−1，X=X 走盘 → 归一化到 {大,小}

四分之一盘 (X.25 / X.75)：拆 (line−0.25, line+0.25) 各半仓 → 半输半赢折算后归一化

归一化公式：P归一(大) = P原始(大) / [P原始(大)+P原始(小)]，P归一(小) 同理

目标：argminλ Σ(模型归一 − 公平概率)²
